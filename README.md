# 自动短视频运营系统（多Agent + GPT版）

生成时间：2026-04-30 16:42

## 一、系统概述

这是一个基于多Agent协同的自动短视频运营系统，实现： - 自动选题 -
GPT生成爆款脚本 - 自动视频生成（可扩展） - 自动发布（可扩展） -
数据分析与优化 - 持续迭代

------------------------------------------------------------------------

## 二、核心模块

### 1. TrendAgent（选题）

自动生成热门内容方向

### 2. ScriptAgent（GPT脚本生成）

调用GPT生成： - Hook（3秒钩子） - Content（核心内容） - CTA（转化引导）

### 3. VideoAgent（视频生成）

当前为模拟，可接入： - FFmpeg - 剪映 / CapCut API

### 4. PublishAgent（发布）

模拟数据（播放/点赞/评论）

### 5. AnalyticsAgent（分析）

计算内容评分，判断是否爆款

### 6. OptimizationAgent（优化）

根据表现自动调整策略

------------------------------------------------------------------------

## 三、运行步骤

### 1. 安装依赖

pip install openai

### 2. 设置API Key

export OPENAI_API_KEY="你的key"

### 3. 运行程序

python main.py
